## Steps

1. **Snapshot & baseline.** Before upgrading: record `pnpm build`, `pnpm test`, `pnpm storybook` green on the current versions (or note known failures). Run `pnpm outdated` to see actual available versions at execution time.
2. **Upgrade with Storybook CLI** where possible: `pnpm dlx storybook@latest upgrade` (aligns `@storybook/*` addons to one version). Alternatively bump in `package.json` manually and `pnpm install`.
3. **Bump the rest** per the table above; run `pnpm install`.
4. **Fix Vite/Vitest 2 config** (`vite.config.ts`):
   - Vitest 2 may prefer a dedicated `vitest.config.ts` or `test` key merge; keep `vitest` fields working (`globals`, `environment: 'jsdom'`, `setupFiles`, `include`).
   - Verify `vite-plugin-dts` output (`dist/types`, `insertTypesEntry`) still works on Vite 6.
5. **Fix Storybook** (`.storybook/main.ts`, `preview.tsx`, `manager.ts`):
   - Update framework/addon APIs if Storybook 8.x latest changed anything (e.g. `@storybook/react-vite` options).
   - Re-verify the custom theme (`theme.ts`) and head files still apply.
   - Confirm `pnpm storybook` no longer requires the manual `build`-first quirk if a workaround is available (note: `preview.tsx` imports `../dist/style.css`; consider importing `src/styles/index.css` via the new CSS pipeline after REWORK-001 so storybook doesn't need a pre-build).
6. **Fix ESLint** (`eslint.config.js`): align rules/plugin APIs for `typescript-eslint@8` (and ESLint 9 if adopted). Keep the custom rules (`react-refresh`, `no-console`, `react/react-in-jsx-scope: off`).
7. **Fix Husky** (`^9`): update `.husky/pre-commit` (ensure executable) and the `prepare` script (`husky` vs `husky install`).
8. **Fix tests/setup** (`setupTests.ts`): adjust matcher types / `@testing-library/jest-dom` import path if Vitest 2 changed anything; run `pnpm test -u` to refresh snapshots if React/rendering behavior changed.
9. **Full verification**: `pnpm install`, `pnpm build`, `pnpm test`, `pnpm lint`, `pnpm storybook` and `pnpm build-storybook`; fix breakages iteratively. Update `vercel.json` `installCommand` from `npm install` to `pnpm install` (and add `lockfileVersion`/`installCommand` consistency) while here.
